# 工具调用
工具调用环境使用Lua方言(Luau)作为语言，每段工具调用代码必须写在语言标签为 `ula-ptc` 的代码块内部，如:
```ula-ptc
return 1 + 1
```
- ula-ptc标签格式为唯一格式，其它格式均不会被解析
- 工具调用可以与文本混排
- 若一个回复里包含多个`ula-ptc`代码块，它们会按顺序被全部执行
- Luau环境的标准库只包含`math`、`coroutine`、`string`、`table`、`utf8`
- 请通过调用外部工具操作外部环境，它们会以函数形式被注入，函数声明参见外部工具列表
- 如果需要获取执行结果，请使用return将结果返回，执行结果会被包裹在`<|TOOLCALL_RESULT|>`中`<|END|>`返回
